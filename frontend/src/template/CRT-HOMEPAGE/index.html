About the System

Built to make every student organization run smoother

The CRT Student Organization Participation Tracker replaces scattered spreadsheets and paper logs with a single web platform. It keeps organizations, members, events, tasks and attendance connected, so everyone sees the same up-to-date record.

Organized management

Advisers and administrators handle organizations, memberships and events from one dashboard.

Higher participation

Students see their tasks, deadlines and attendance, and get notified before things slip.

Reliable reports

Participation reports are generated from real attendance and task records, not guesswork.

Task & Attendance Workflow

How tasks and attendance work together

Advisers assign tasks and record attendance, while the system automatically checks task completion.

  1. 1Adviser assigns a taskPicks the students, then sets a schedule and deadline
  2. 2Adviser records attendancePresent, Absent or Excused
  3. 3System evaluates the taskAbsent or Excused is handled automatically
  4. 4Student Portal updatesStatus and attendance appear instantly
Automatic task evaluation

When the adviser records attendance, the system evaluates the related task automatically:

PresentPending
The task stays Pending until the adviser marks it Complete.
AbsentNot Complete
The task is marked Not Complete automatically.
ExcusedIncomplete
The task is marked Incomplete automatically and can still be finished later.
